# 《磚3》V8 戀愛關係深化與動態人生系統（修正版）

> 狀態：**開發規格，尚未實作**。以《磚3》V7 五位男主角設定為基礎。此文件不是功能完成證明。

## 核心守則

- 保留 FoundPhone 原有 KKT、Instagram、照片、通知、日曆、聯絡人、存檔與手機介面。
- 玩家是成年上班族女性；五位男主角為沈硯舟、裴知聿、祁野、顧時安、陸沉川。
- 各 NPC 有獨立行程、職涯、朋友、家庭與選擇權；玩家未開聊天室仍能收到排程訊息。
- 好感、信任、親密、忌妒、依戀、佔有慾、失去關係的焦慮等數值對玩家隱藏。數值不單獨決定行為。
- 玩家可拒絕、維持曖昧、交往、分手、復合、秘密交往或協商知情同意的非排他關係。NPC 可以拒絕；所有親密互動需雙方同意。
- 五位男主角均不永久退出世界，但必須尊重玩家明確拒絕、停止追求或停止聯絡的界線。
- 事件須符合時間、已知資訊、玩家實際選擇與歷史記憶；不得代玩家答應約會、出席、交往或親吻。

## 1. 告白與多重關係

當玩家已有戀人時，其他人的告白**不能覆蓋舊戀人**。新增六種處理：
1. 選擇新告白者（另行處理原關係，不能自動分手）。
2. 提議公開非排他關係（開啟逐人協商，不等於自動接受）。
3. 暫時不決定（最多 14 個遊戲日可回覆；NPC 可追問、撤回或改變心意）。
4. 拒絕。
5. 提議秘密交往（對方有權拒絕；不得視為所有相關人已同意）。
6. 維持曖昧但不確認交往。

首頁新增「今日關係決定」：未送達、未造成外部後果的決定可撤銷；已送達的內容及他人已知資訊不可神奇抹除。完整回溯必須另外建立明確的劇情檢查點。舊存檔有戀人被欄位覆蓋跡象時，顯示一次性「關係恢復中心」，以證據恢復，不可捏造歷史。

公開非排他協商的開場提供「全部說清楚／先說明現有戀人／先試探看法」。每位 NPC 可接受、有條件接受、需要時間、暫時拒絕或明確拒絕。記錄個別約定：是否專一、公開程度、知情範圍、約會與親密界線、告知義務。**高好感不等於同意非排他戀愛。**

### 五位男主角的感情立場

- **沈硯舟**：真誠熱情、有原則，重視獨特陪伴；可能嘗試接受，但會嫉妒，也會直接表達不滿。
- **裴知聿**：**最新正式性格為「陰濕重力系男」；禁止沿用「狐狸 80%＋黑貓 20%」**。25 歲心理學研究所碩士生、玩家前男友；依戀沉重、敏感多疑、佔有慾強、害怕被放下，仍希望復合。當玩家已有戀人、他長期無法復合且未被明確要求停止追求時，**可能自願提出當第三者或地下情人**。這不等於真正接受公開多戀：他仍會嫉妒正式戀人、期待被優先選擇，也可能在日後要求公開或退出。不可將他固定寫成理性毒舌的狐狸型心理交鋒者；不得用威脅、自傷或強迫取得回應。
- **祁野**：23 歲祁家次子，張揚好勝、偏向排他，可能挑釁競爭者，亦可能成長。
- **顧時安**：26 歲建築設計師，成熟細膩、有原則；相對願意協商但重視誠實，理性理解不等於情緒無負擔。
- **陸沉川**：26 歲江南陸家繼承人、集團副總裁，辦公室位於玩家公司隔壁；高冷、外冷內熱，擅長鋼琴與料理；感情須自然建立，玩家保有選擇權。

## 2. 秘密關係、第三者與修羅場

每人獨立記錄 relationshipKnowledge：知道的人物、關係、親密事件、資訊來源、可信度及懷疑。私訊不得被其他 NPC 無理由讀取。秘密曝光需有公開貼文、照片、共同活動、本人告知等可追蹤來源。

裴知聿專屬的第三者劇情：
- 不甘心：得知玩家現任後，仍有未解的前任感情。
- 降低要求：不再堅持立刻復合，試探私人聯絡可能。
- 提議地下戀情：可能自己開口；玩家可以拒絕，拒絕即不成立。
- 秘密戀情的矛盾：若雙方同意，依戀與忌妒可能並存。
- 重新選擇：坦白、公開協商、希望專一、維持秘密、分手或退出均是可能分支。

在戀愛關係卡新增「向相關戀人坦白」，可一次告知或逐一告知；主動坦白不保證原諒。親吻事件記錄日期、同意、對象和當時約定；違反專一承諾可能導致信任危機，未約定專一不得一律判作背叛。

修羅場《為什麼他也這樣叫妳？》：必須有人在合理場合聽見親密稱呼，且知道足夠背景。玩家可「坦白／暫停現場稍後談／模糊帶過／拒絕公開回答」。事件可跨日產生後果；裴知聿可能私下反覆確認，但須遵守拒絕界線。五男主共有十種兩兩組合，不能只替換姓名套用台詞。

## 3. 心理觀察與深層人格

替代他作中的「員工心理觀察」為《磚3》人物心理觀察。玩家可透過 KKT、Instagram、照片及共同經歷理解工作壓力、疲勞、被忽略、曖昧不明、家庭問題、忌妒、職涯挫折等；不把所有情緒歸咎玩家。取得兩條內核線索或深入談話詢問需求後，才顯示更具體的**已知觀察**；不可讀心或顯示隱藏數值。

「人格覺醒」改為**深層人格顯露**，依長期互動、內核、角色意願及重大事件觸發，符合時排入未來三天的候選事件，遇日程衝突順延。不能因好感 95 強制變人格。一般生氣、拒絕與嫉妒不必等覺醒。

專屬事件：
- 沈硯舟《不只是陽光的那一面》：首次直接承認委屈與嫉妒。
- 裴知聿《只要還能留在妳身邊》：陰濕重力系、失去前任身分後降低要求，願當第三者卻無法不嫉妒。
- 祁野《輸不起的人》：家族與好勝背後的無力感。
- 顧時安《理性以外》：不再將情感需求全部理性化。
- 陸沉川《下班後的真心》：在集團責任與私人情感之間逐步建立信任。

## 4. 職涯專精與人物內核

不新增雇員/培訓經營；NPC 自主透過工作與生活提升三類專精，基礎能力 100 後累積專精經驗，每人最多三個里程碑：
- 沈硯舟：攝影／運動合作／影像企劃。
- 裴知聿：心理學研究／訪談分析／學術合作。
- 祁野：品牌企劃／視覺設計／活動組織。
- 顧時安：建築設計／專案管理／設計倫理。
- 陸沉川：集團經營／鋼琴／料理。

內核四階：CORE_01 異常 → CORE_02 證據 → CORE_03 真相入口 → CORE_04 主動坦白。個別主題：
- 沈硯舟：攝影作品署名與自我價值。
- 裴知聿：分手後依戀、共同過往、害怕失去與可能願當第三者。**分手原因尚未確定，不得擅自寫死。**
- 祁野：家族利益與個人自由。
- 顧時安：專業倫理與現實妥協。
- 陸沉川：江南陸家繼承責任、集團管理與私人真心。

END_01 專一的選擇；END_02 不只一種愛（全員知情同意）；END_03 秘密的代價；END_04 破鏡重圓（裴知聿）；END_05 錯過的告白；END_06 我們仍然是朋友；END_07 各自的人生；END_08 修羅場之後；END_09 真正的他；END_10 五個人的交會；**END_11 不能公開的愛（裴知聿第三者專屬）**。所有結局是可繼續遊玩的階段節點，不凍結世界。

## 7. UI、資料、時間與驗收

- KKT 必須逐則送達、停頓、有問有答；玩家可回覆五男主與其他既有可互動人物。裴知聿焦慮時可連續訊息，但不可無限重複或越過明確界線。
- Instagram、照片、通知、日曆及關係卡須同步人物職涯、約會確認、已知線索和秘密曝光來源；不得洩漏角色未知資訊。
- 玩家不打開聊天室，NPC 仍在合理排程下傳訊與生活；離線時不得替玩家答應邀約、告白、出席或親吻。
- 結構化持久化欄位至少包括 characterId、relationshipStatus、exclusivityAgreement、relationshipHistory、confessionStatus、confessionDeadline、relationshipKnowledge、trust、affection、intimacy、jealousy、jealousyByRival、attachmentLevel、possessiveness、abandonmentAnxiety、secretRelationshipStatus、thirdPartyWillingness、psychologicalState、coreStage、coreClues、personalityRevelation、careerExperience、careerSpecializations、eventHistory、pendingEvents、playerChoices、undoHistory。
- 多戀必須使用**多關係資料結構**，不得以單一戀人欄位覆蓋；事件有穩定 ID、觸發時段、狀態與去重紀錄；舊存檔須遷移，保留既有聊天、照片、關係與玩家決定。
- attachmentLevel、possessiveness、abandonmentAnxiety、thirdPartyWillingness 僅為敘事模擬內部變數，不是醫療診斷。

### 實作階段

1. 關係資料模型、告白分歧、關係恢復。
2. 公開/秘密非排他關係、裴知聿第三者分支、坦白與修羅場。
3. 心理觀察、深層人格、CORE 線索。
4. 職涯專精、七夜間事件、十一階段結局。
5. KKT、Instagram、照片、日曆、關係卡整合。
6. 存檔遷移及完整回歸測試；執行 `npm run story:validate`、`npm run story:test`、`npm run build`；若動到引擎，另跑 typecheck、lint、單元與相關瀏覽器測試。

驗收要點：新告白不覆蓋舊關係；NPC 可自主拒絕多戀；裴知聿是陰濕重力系且可在合適情境提出秘密第三者關係；所有行為仍需玩家同意；秘密有真實傳播路徑；跨日事件、關係及存檔保持一致；原有 FoundPhone 核心功能不受損。
