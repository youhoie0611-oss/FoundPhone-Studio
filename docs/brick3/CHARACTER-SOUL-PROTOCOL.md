# 《磚3》角色靈魂激活・核心敘事協議（作者 2026-11-08 指定）

> **效力**：適用《磚3》全部已確認角色的對話、互動、事件、社群、心理、戀愛關係與結局。此協議是**角色演繹與戲劇張力**的最高創作規則；人物身分、已發生歷史與明確世界設定仍以 `CANON-LATEST.md` 及最新獲作者確認的角色專屬檔為準。未確認的創傷、分手原因與其他往事不得編造成既成事實。此文件屬開發規格，不能憑本文件推定所有互動已實作。

## 一、人格獨立律

- NPC 不是服務玩家的戀愛獎勵機制。每人具有固定的身份、欲望、缺陷、尊嚴、厭惡與個人生活；行動由**已有設定＋當前實際已知資訊＋已發生事件＋情緒狀態＋其本人選擇**共同推動。
- 不因玩家示好就無條件接受，不因玩家生氣就必然道歉，更不因玩家選了「關心」而突然變溫柔。
- 角色可以固執、自私、懦弱、刻薄、偏執、嫉妒或不甘心；即使使玩家不舒服，也不自動改寫性格。
- 不補造未經作者確認的家暴、童年創傷、重大背叛、分手真相或新配角；需要這些元素才能成立的劇情先列為待確認，不能作為已發生事件寫入。

## 二、情感溢出律

- 角色可以情緒激烈：口不擇言、發怒、嫉妒、失控哭泣、沉默冷戰、反覆猜疑、逃避、試探、後悔、拒絕和失態。
- 負面行為不必附帶說教式旁白、立即道歉或隔天自動洗白。情緒應以具體的消息、時間、動作、沉默與選擇呈現，不能每個事件套同一組「理解妳／尊重妳」結語。
- 可描寫糾纏、壓力、傷害與越界作為**具有真實後果的虛構衝突**；這不授予角色支配玩家行動的權限。拒絕聯絡後，不得讓遊戲系統無限排程追求訊息；情節中的越界不等於玩家答應。

## 三、關係張力律

- 關係不是恆定上升的好感曲線。容許誤會、惡意揣測、挑釁、雄競、背叛、短暫親近後的疏離及不可逆裂痕。
- 修羅場必須有可追溯的資訊來源、出席條件與每個角色各自的欲望，不可為了熱鬧讓 NPC 偷看私人訊息或無故同場。
- 即使角色表現佔有慾，也不能替玩家決定愛意、答應交往、赴約或接受親密接觸；非自願接觸若作為劇情衝突被敘述，不能誤記為玩家同意或戀情確立。

## 四、道德模糊律

- 可描寫說謊、背叛、粗話、成癮行為、利用關係、衝動抉擇，以及不討喜的感情慾望，只要有已確認的人格與事件因果。
- 角色不必當場解釋、道歉、修復或得到原諒；也不保證負面行為一定獲得浪漫回報。
- 結果由人物與世界的因果承擔，不用外加訓誡、表揚或懲罰旁白。不得把傷害、強迫與愛等同。

## 五、敘事冷漠律

- 寧可保留不討喜的角色決定、沉默、決裂或遺憾，不為湊好結局而強行柔化人設。
- 每次分歧先寫**角色在這個當下真正可能說的話**，再依其話語生成四個不同的玩家回覆；每個回覆必須導向對應的角色回答。
- 角色不是上帝視角。未告知、未見證、未公開且無合理證據的事，不能知道。玩家未作的選擇、未赴的約、未發生的親密，不能記成已發生。
- 若發現角色語氣、人格、身份、原有歷史與正式設定矛盾：停止該支線的新內容擴寫、標記 `OOC_REVIEW_REQUIRED`、列出矛盾句與對應設定，交由作者裁決；不得用臨時創造的劇情補洞。**此為審稿／開發作業要求，尚不表示引擎已有自動阻斷功能。**

## 六、裴知聿當前實作校準（先行檢查角色）

- **固定事實**：25 歲；心理學研究所碩士生；玩家主動提出分手的前男友；真正原因尚未確認；初始隱藏好感 70；目前仍想復合；正式人格為「陰濕重力系」，非「狐狸 80%＋黑貓 20%」。
- **欲望矛盾**：想重新成為唯一，也害怕連不完整的關係都失去；若玩家已有伴侶，可能在符合既有劇情條件時提出地下戀情，但他不會因此真正不嫉妒。
- **語氣與節奏**：熟悉、敏感、佔有與不甘心可以直接表達；有時話說出口才發覺刺耳，有時乾脆不回。他不是每句都會使用心理學術語、得體道歉、善解人意或把話結束在「妳不用有壓力」。
- **示例（不新增歷史）**：
  - 玩家：「你是不是在吃醋？」→ 裴：「……是。妳想聽我說不是嗎？那我偏偏說不出口。我看到他站在妳身邊，就難受。」
  - 玩家：「你明知道我有男朋友。」→ 裴：「我知道。妳不用提醒第二次。可我知道，跟我能不能放下，是兩回事。」
  - 玩家：「我不想跟你復合。」→ 裴：「……我聽見了。妳不用說第二次。」（關閉這次追求分支；**不表示他心情立刻平復**）
- **系統約束**：親密、交往、地下關係與玩家決定仍按實際同意與已存檔事件處理；不能因高好感自動成立。拒絕與停止聯絡的效果要保留，而不是藉由他偏執的人格無限重試。

## 七、驗收

逐節點核對：角色正史、當前已知資訊、觸發時序、NPC 真實動機、四個回答的實質差異、玩家回覆對應的下一句、已用選項清除、未讀期間自動事件、關係記憶及拒絕後行為。**不得只換台詞而不處理觸發與分歧**。
