# 《磚3》人物資料庫

本目錄**只屬於《磚3》**。不修改既有 characters/ 或其他遊戲版本。

## 每位角色資料夾
- profile/：人物核心設定、外貌參考、關係與版本紀錄
- instagram/photos/：Instagram 貼文與限時動態圖片
- instagram/stories/：**每張 Instagram 圖片**的故事、文案、時間、可見權限與事件連結
- messages/photos/：角色於私訊或群聊發送的圖片
- messages/dialogues/：**每張聊天室圖片**的發送背景、完整對話、時間、收件人、分歧及事件連結

## 素材規則
1. 上傳前辨識角色、用途與故事；每張圖片使用唯一 ID（例：IG-0001、MSG-0001），圖片與故事／對話檔以相同 ID 對應。
2. 故事檔標示：圖片 ID、角色、事件 ID、遊戲日期時間、場景、拍攝／取得者、圖片內容、貼文文案、可見對象、前因後果、分歧條件、實際圖片路徑、狀態。
3. 對話檔標示：圖片 ID、角色、事件 ID、遊戲日期時間、發送者與收件者、發送前對話、圖片訊息、圖片後的逐則對話、玩家可選回覆、條件與後果、實際圖片路徑、狀態。
4. NPC 不得憑空取得私訊內容；公開與私密照片須遵守可見權限。時間、人物日程與前情保持一致。
5. 圖片不存在時只能標記「待上傳」，不可宣稱成功。每次提交回報實際檔案路徑、commit 及 GitHub 資料夾連結。
6. 不自行創造尚未確認的圖片故事或玩家選擇；必要時可先建立待補欄位。
