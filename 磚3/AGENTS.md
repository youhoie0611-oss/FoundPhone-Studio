# 《磚3》開發與素材生成要求

本目錄僅屬於《磚3》；只改動 `磚3/` 內的故事／角色資產及該版本明確引用的資料。保留 FoundPhone 既有手機介面與核心功能，不擅自調整其他版本。

任何角色新照片或外觀修改：先讀 `磚3/visual-memory/registry.json` 及相應 `磚3/characters/<姓名>/profile/visual-memory.json`，**實際載入目前核准的參考圖片**。如果 imageAvailability 為 pending，不能只用名字或舊人物圖直接產圖並宣稱視覺一致。

裴知聿最新確認的是 2026-11-05 黑色高領 V2 多視角人物板（`磚3/characters/裴知聿/profile/visual-memory.json`）；先前灰色連帽外套參考只能作歷史與穿搭補充，不是目前的臉孔生成依據。

依照角色 metadata 將 KKT／IG Story／IG Post 照片分別儲存。每次要回報照片檔名、用途、對應 GitHub 資料夾 URL、實際提交狀態及 commit。未上傳的圖必須標成待上傳；不能宣稱已提交、已在遊戲觸發。人物背景不因參考板上的尺寸標籤或待選場景自動改寫。
