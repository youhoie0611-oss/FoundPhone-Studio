# 祁野｜圖片素材分類

這個目錄專門放《磚2》祁野的圖片素材，依 **使用情境** 分流，避免同一張圖片被錯誤當成聊天、限時動態或正式貼文。

| 用途 | 目錄 | 格式建議 |
| --- | --- | --- |
| KKT 對話傳給玩家 | `chat/` | 自然手機照片；自拍或祁野自己拍的 POV |
| Instagram 限時動態 | `instagram/story/` | 9:16 直式；可有簡短文字，但不要預設公開情緒 |
| Instagram 正式貼文 | `instagram/post/` | 4:5 直式或 1:1；符合祁野本人會公開的照片 |

## 後續每張新圖的固定交付方式

1. 生成時自行判斷唯一主要用途（KKT / IG Story / IG Post）；不清楚時按照片敘事目的分類。
2. 在回覆中標示 **照片主題、分類、建議檔名、GitHub 目標資料夾**，並附上該資料夾的 **GitHub 上傳頁面連結**。
3. 能成功提交圖片時，另附 **已確認的圖片檔案網址與 commit**；只有資料夾／腳本提交、未上傳圖片時，必須明說沒有上傳圖片。
4. 除非另有明確確認，照片中的事物只是素材候選，不等於祁野已經公開貼文、擁有寵物、與玩家交往或發生該事件。
5. 實際進入遊戲時再同步修改劇情腳本，並處理素材可讀路徑、訊息時間、已讀通知與選項分支。

檔名規則（全英文小寫、底線分隔）：
- KKT：`qiye_chat_<topic>_<nn>.jpg`
- IG Story：`qiye_story_<topic>_<nn>.jpg`
- IG Post：`qiye_post_<topic>_<nn>.jpg`

不要在錯誤的媒體分類放置同一圖片。每次提交後以 GitHub 實際檔案路徑為準。

## 固定人物外貌基準

祁野已確立第 1 版視覺錨點。每次生成照片前先參閱 [祁野視覺記憶檔](./visual-memory.json) 和 [參考圖資料夾](./reference/)。原始設定圖於對話中提供，GitHub 高解析原圖尚待上傳，請勿宣稱圖片已存入儲存庫。

此原則適用以上三個照片分類。自拍可以變換衣服及光影，但不能變臉；KKT 私訊原則上應是角色本人合理可拍的手機 POV 或自拍。

## 照片生成／傳送 V3.0

以 `stories/qiye/PHOTO_POLICY_V3.md` 與 `stories/qiye/photo-policy-v3.json` 為準。

- 先確定**拍攝者、入鏡人物、情緒、服裝、時間與事件**，再生成候選素材；**照片生成不等於遊戲已拍攝，也不等於傳給玩家**。
- 一般以祁野自己的手機 POV、自拍為主；**如果劇情已有確實同行的 NPC**，允許該 NPC 幫拍祁野，或與已存在的 NPC 合照。不得創造不存在的朋友／合照角色。
- 適合公開的限動與貼文分別放 Story / Post；私訊照放 KKT chat。分流是素材管理，不等於社群已發布。
- 照片不必每張好看，需依長期內容參考比例及生活事件呈現耍帥、搞怪、狼狽、疲憊、安靜等差異。
- 所有正式生成都須載入**祁野真正的視覺參考圖**，並與視覺記憶比對；同一天服裝與現場情境保持一致。
