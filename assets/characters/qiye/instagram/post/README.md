# 祁野｜Instagram Post 正式貼文

這裡放祁野**自己拍攝並可能選擇公開發文**的日常作品或紀錄。

- 建議 4:5 或 1:1；比私訊更有挑選感，但仍要像他本人會分享的照片。
- 題材可包含街頭攝影、運動、設計作品、旅行與生活片段；照片不必次次露臉。
- 不要擅自補寫貼文文案、發布日期、按讚留言或標記其他人為已發生事實。
- 較正式、經過挑選的照片放此處；即拍即傳的日常優先歸到 chat 或 story。
- 素材先上傳，不代表貼文已發布；需和遊戲 Instagram 內容及劇情進度同步。

命名範例：`qiye_post_city_night_01.jpg`

上傳位置：`assets/characters/qiye/instagram/post/`
