# 祁野｜Instagram Story 限時動態

這裡放祁野**自己拍攝並可能公開到 IG 限時動態**的照片。

- 建議 9:16 直式畫面，內容如街頭運動、雨景、夜景、臨時聚會、音樂、食物與設計日常。
- Story 是社群動態，不等於已私訊玩家；玩家是否看到、能否回覆依遊戲設計。
- 要符合祁野張揚、叛逆但有自己生活的性格；不因玩家存在而固定發曖昧暗示。
- 不要把別的角色的動態混入祁野個人限時動態。
- 圖片生成與上傳並不代表該動態已經發布；需有正式事件、日期及可見狀態。
