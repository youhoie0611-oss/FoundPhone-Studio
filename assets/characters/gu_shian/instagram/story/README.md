# 顧時安｜Instagram 限時動態照片

此資料夾專門存放**顧時安以自己帳號發布的 Instagram Story** 圖像，不與 KKT 私訊或 Instagram 正式貼文混放。

## 內容原則

- 以顧時安 26 歲、建築設計師的獨立生活與個人審美為核心；素材可以是他自己拍的工作、建築、城市、飲食、休假、攝影、日常細節。
- 不能因為玩家想看照片，就預設他已經和玩家交往，或為了戀愛機械式天天更新動態。
- 自然手機拍攝感、生活紀錄感優先；直式 9:16 為預設構圖，避免大量文字和水印。
- 不得透露未經允許公開的客戶、工地、工作圖面、個人或第三方隱私。
- 每張照片需有獨立 ID、檔名、簡介、拍攝者、動態發布條件及劇情對應關係；照片尚未真正上傳前不得標成已發布。

## 命名

`gu_story_YYYYMMDD_主題_01.jpg`，例如 `gu_story_20261104_rainy_window_01.jpg`。日期應是**劇情設定中的拍攝日期**，不是硬套上傳日期；日期未定時用 `undated`。

## 素材存放與回報

- 本資料夾：`assets/characters/gu_shian/instagram/story/`
- 若照片未能完成 GitHub 二進位上傳，明確標示「照片已生成，尚未上傳」。
- 每次成功上傳後，應附本資料夾 GitHub 連結以及可驗證的 Commit。
- 發布到 Instagram Story 的事件需另經遊戲劇本整合；放入資料夾不代表遊戲已可看到。
