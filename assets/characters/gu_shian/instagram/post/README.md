# 顧時安｜Instagram 正式貼文照片

此資料夾專門存放**顧時安以自己帳號發布的 Instagram Post** 照片；與限時動態、KKT 聊天照片分開管理。

## 內容原則

- 以顧時安的建築設計、城市觀察、旅行、日常興趣與個人審美為主，符合獨立生活設定；不把每篇貼文寫成對玩家示愛。
- 畫面可較限時動態更講究構圖與色調，但仍是他個人拍攝或合理自行發布的內容。
- 單張照片預設 4:5；若為輪播，同一貼文各張應使用一致長寬比與相同貼文 ID。
- 投稿時間、文字、標籤、是否有定位及是否被玩家看見，須符合事件先後與可得資訊；不得擅自推進感情狀態。
- 避免客戶機密、未授權第三方影像與版權素材。

## 命名

`gu_post_YYYYMMDD_主題_01.jpg`，例如 `gu_post_20261104_concrete_light_01.jpg`。日期為**故事內發布日期**，尚未安排日期則用 `undated`。輪播依序 `01`、`02`、`03`。

## 素材存放與回報

- 本資料夾：`assets/characters/gu_shian/instagram/post/`
- 每張圖需對應描述、發布文案及遊戲事件；原圖未上傳不可假稱已存在於 GitHub。
- 每次成功上傳後，應附本資料夾 GitHub 連結以及可驗證的 Commit。
- 本目錄的檔案不會自動變成遊戲內貼文，仍須另行整合進正式劇本。
