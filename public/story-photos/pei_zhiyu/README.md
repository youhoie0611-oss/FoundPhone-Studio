# 《磚3》裴知聿 劇情照片

請將 WebP 圖片上傳至這個資料夾，使用劇情配置中的**完整檔名**。不要只更改副檔名，實際檔案必須是 WebP。

## 已配置照片檔名

- `pei_zhiyu_dinner_chat_01.webp`
- `pei_zhiyu_dinner_visit_table_01.webp`
- `pei_zhiyu_dinner_visit_cooking_02.webp`
- `pei_zhiyu_dinner_visit_livingroom_03.webp`
- `pei_zhiyu_dinner_visit_hands_04.webp`

相片傳送及相簿解鎖由編譯時的 `docs/brick3-photo-events-v1.json` 和 `scripts/brick3-photo-events.mjs` 控制。遊戲先確認故事事件與玩家選擇，再檢查照片是否已在已部署的網站中存在。缺圖時不會顯示破圖。
