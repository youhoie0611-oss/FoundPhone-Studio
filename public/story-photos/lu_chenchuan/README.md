## 二、四類照片

1. **職場**：辦公室、會議、落地窗夜景、文件、商務出差與正式活動；可以是環境、背影、手部、自然側拍，不得使用男模棚拍、會館或陪酒情境。
2. **私人生活**：住家下廚、餐點、鋼琴與樂譜、書房、採買、散步、朋友聚會、生活自拍。必須有自然手機感，不得全部像廣告。
3. **家族**：宅邸局部、家族晚宴與集團活動，屬高隱私素材；初識階段不得提前揭露身分、家庭住址或私密聚會。
4. **關係進展**：初識可分享辦公大樓周邊、咖啡與街景；熟悉後可分享料理、鋼琴與生活照；曖昧後才有約會紀錄；確立關係且確實發生後才有共同旅行、居家或親密回憶。不得靠單一好感值跳過事件。

## 三、照片真實性

每張照片必須交代拍攝者、時間地點、拍攝原因、當下心情、分享動機及玩家是否有權看到。不可憑空加入玩家身影、預設共同經歷或公開私人照片；公開 Instagram、私人 KKT 附件與玩家相簿須分開管理。照片分享不等於自動存入相簿。

## 四、主動聯絡與四選項分歧

- 角色有獨立的工作、家族、鋼琴、料理、朋友與休息日程；符合條件的訊息不依賴玩家是否打開聊天室。
- 訊息自然分段並有停頓；玩家可回覆，四個選項需分別提供自然關心、輕鬆調侃、延伸話題、禮貌保持距離等**不同意圖**，不能四個選項只換字或全部導向同一情感結果。
- 未讀、已讀未回、拒絕與明確界線必須受到尊重；不連續騷擾、不預知玩家未告知的資訊。
- 私人 KKT 聯絡方式須在雙方同意後建立；工作往來、身分地位、禮物或邀約本身都不代表戀愛關係。
- 好感度及信任為隱藏值，須結合已發生的事件、雙方選擇、角色當下狀態與未解衝突；不能用數值取代劇情因果。

### 範例：21:36 晚間料理

前置：已互相同意交換私人 KKT；陸沉川當日結束工作、回家做晚餐；無互斥衝突事件。

陸沉川依序傳送（訊息間有自然延遲）：「剛到家。」「今天開會開得有點晚。」附實際存在的晚餐照片，再傳「晚餐只能簡單做了。」

玩家四選項：
1. 「這叫簡單做？你對簡單是不是有什麼誤解？」→ 含蓄玩笑。
2. 「看起來很好吃，你平常都自己煮嗎？」→ 料理習慣話題。
3. 「忙到這麼晚還自己煮飯，不會很累？」→ 可談工作壓力。
4. 「辛苦了，早點休息吧。」→ 尊重休息，不強行延長對話。
