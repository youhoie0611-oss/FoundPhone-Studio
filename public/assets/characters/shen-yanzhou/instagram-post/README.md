# 沈硯舟｜Instagram Post（貼文）素材

此資料夾存放沈硯舟會放在個人 **Instagram 一般貼文** 的圖片，例如完成的攝影作品、球場或活動紀錄、朋友聚會與認真想分享的日常。

## 收錄原則

- 較 Story 更有選擇性與個人審美，但仍是同一個人所拍，不要求商業棚拍質感。
- 建議方形 1:1 或直式 4:5，若為多圖輪播則保持同一貼文的敘事一致性。
- 對應照片必須尊重現有角色設定與活動拍攝的肖像同意，不能自行公開玩家的照片。
- 檔名採 `shen-post-<scene>-<sequence>.webp`。遊戲引用：`./assets/characters/shen-yanzhou/instagram-post/<filename>`（需先確認程式支援）。
