# 沈硯舟｜與玩家聊天的照片（KKT / Chat）

此資料夾專門存放沈硯舟會**私下傳給玩家**的圖片。包含本人自拍、第一人稱生活照、學校／健身／運動／攝影日常、與玩家對話時主動分享的照片。

## 收錄原則

- 像沈硯舟親自拍的：自然手持角度、生活化光線，偶有不完美構圖；符合他當時的行程與相處階段。
- 一般生活分享不等於告白；自發傳送要配合劇情、合理時機與玩家界線。
- 每張圖檔名使用英文小寫和連字號，例如 `shen-chat-gym-after-workout-01.webp`。
- 遊戲聊天引用預期使用相對路徑 `./assets/characters/shen-yanzhou/chat/<filename>`；上傳後須先檢查媒體白名單與實際訊息事件，才能宣稱已在遊戲中出現。

**提醒**：本資料夾新建前的既有聊天照片位於上一層 `public/assets/characters/shen-yanzhou/`，目前仍供遊戲劇情使用，**不可直接搬走或刪除**，避免原有照片連結失效。
