# 祁野｜補充設定及遊戲同步規則

此資料夾是《磚2》祁野的角色專屬編輯來源。本對話框以角色人設、家庭、生活、心理、對話、自拍與手機 POV 生活照、個人支線與分支補充為主。

- **角色真實設定**：以 `character-profile.json` 的 `canon` 欄位為準。使用者明確確認的新設定優先。
- **遊戲入口**：`stories/template/story.json` 是目前預設執行腳本。已將祁野加入 contacts 與 KKT 聊天室；後續劇情要真正遊玩，仍需在該腳本實作事件、互動、訊息與條件。
- **圖片故事**：`photo-events.json` 是六張生活照的待整合企劃，不代表已在遊戲引擎中生效；JPEG 上傳且格式/路徑校驗通過後，才能接入。
- **照片拍攝來源**：祁野自己拍、手機視角或合理自拍；不能用攝影師視角偽裝成角色傳送。
- **每次新增/修改**：核對既有事件記憶、隱藏好感度、四種分支、時間軸、回覆停頓與離線自主訊息；同步正式腳本及補充檔，避免兩份設定衝突。
- **不臆造**：沒有確認的相識方式、職業、家族事件、交往關係或動物飼養權，不得當作既成事實。
- **交付要求**：有要求提交時，需要回報實際 GitHub commit 及路徑；未完成整合或未驗證的部分應分開標明。聊天本身不會自動在背景推送 GitHub。

主要設定依《磚2》核心世界觀及分支企劃；玩家可維持單身，祁野有獨立生活，不是只為推動戀愛存在。
