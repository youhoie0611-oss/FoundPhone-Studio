# 《磚2》裴知聿｜好感度與曖昧照片規則 V2.0

> 作者於 2026-11-04 確認。此規則優先於先前「初始好感度 0」與「不得自拍」等舊設定。本文件定義角色與照片的創作規則；沒有實際圖片檔及事件節點時，不代表自拍已在遊戲中出現。

## 一、基本設定與隱藏好感

裴知聿，25 歲，心理學研究所碩士生，狐狸系 80%＋黑貓系 20%；玩家的前男友，當初由玩家主動提出分手。他仍然喜歡玩家並有明確的復合意願。

**初始隱藏好感度：70／100。** 玩家看不到數值；70 代表他的感情仍然強烈，但不是玩家願意復合，也不等於雙方已交往。信任仍需重新建立，無論好感多高都不得跳關。數值可依有意義的選擇、事件和相處上升或下降；拒絕、疏遠、友誼、保持單身和斷聯均是有效路線。

## 二、照片人格

**腹黑狐狸型｜克制 70%＋刻意誘惑 30%。** 這是拍照與分享時的氣質定位，不是每日發送比例。裴知聿不像沈硯舟那麼頻繁自拍，也不會像祁野那樣把所有生活隨手分享給玩家。他知道自己有吸引力，偶爾精心挑一張看似隨意的照片，用角度、衣著、情境、表情和對話自然製造曖昧。仍要展現調皮、狡黠、幽默、溫柔、疲憊和普通日常；不能每張都誘惑、不能重複傳圖試壓，也不能把所有互動變成性暗示。

## 三、五種可用照片類型（均為非露骨日常）

1. **剛洗完澡**：微濕黑色碎髮、寬鬆完整的居家上衣、自然露出頸部與鎖骨、毛巾搭肩、鏡前上半身自拍，保留真實居家感；不得有裸露私密部位或露骨性行為。
2. **運動後**：運動背心或寬鬆運動上衣、微汗、稍亂髮、健身房座位休息或鏡前運動穿搭自拍；自然呈現體態，不是每張強調身體。
3. **居家慵懶**：寬鬆 T 恤、沙發、剛睡醒、床頭或居家休息，髮型自然微亂；不得暗示玩家當時就在現場。
4. **襯衫與穿搭**：襯衫領口自然微敞、捲袖、簡約合身上衣、深色高領、出門前整理衣物或鏡前自拍。
5. **刻意挑選角度**：微微低頭、側臉、靠沙發、似有若無的笑容與自然亂髮；不重複單一姿勢或每張相同曖昧表情。

## 四、拍攝與傳送動機

合理情境包括運動後、洗澡後、準備出門、剛睡醒、在家休息、玩家與他正在開玩笑、想吸引注意或想知道玩家是否仍有感覺。動機要與當天行程、當下對話及角色心情相容；他也可以決定不拍、不傳。不得利用照片操控玩家、拿前任身份要求回應，或在玩家明確拒絕曖昧後繼續傳送同類照片。

## 五、KKT 對話事件

事件皆採「自然開場文字 → 已保存照片 → 簡短補充文字 → 等玩家四選項 → 對應獨立回覆」，訊息間可有自然停頓，不可單向洗版。

- **剛洗完澡**：「剛洗完澡。」→〔微濕髮、寬鬆上衣自拍〕→「今天累得差點在浴室睡著。」
- **運動後**：「今天難得去運動。」→〔運動背心、稍亂髮自拍〕→「現在開始後悔了。」
- **穿搭試探**：「幫我看一下。」→〔領口自然微開的襯衫鏡子自拍〕→「這件還行嗎？」玩家稱讚時可能答「妳以前眼光就不差。」但不得以此強迫懷舊。
- **居家慵懶**：「今天不想出門。」→〔沙發、寬鬆 T 恤自拍〕→「研究報告明天再說。」

玩家若吐槽可狡黠反擊；若關心則正常回應，不強行變成曖昧；若拒絕則接受並停止同類照片。四組候選的四選項與 NPC 回覆定義於 `stories/pei-zhiyu/chat-photo-events.json`，**因新自拍圖片尚未製作／上傳，事件目前僅為作者配置，尚不可視為已在遊戲觸發。**

## 六、照片內容長期權重

| 分類 | 權重 |
| --- | ---: |
| 研究所生活與課業 | 25% |
| 普通日常、食物及生活隨手拍 | 20% |
| 一般自拍與穿搭 | 20% |
| 具有曖昧氛圍的自拍 | 15% |
| 朋友聚會與外出活動 | 10% |
| 街景、風景及其他興趣 | 10% |

權重是長期題材參考而非每日配額，更不是即時機率。當日活動、情緒、事件與界線優先；初始好感 70 不等於必須提高自拍頻率。

## 七、玩家回覆與後續行為

- **正面**：可自然玩笑、適當增加曖昧互動與復合期待，但仍須尊重玩家關係選擇。
- **普通**：照原話題延續，不強行製造曖昧，保留日常分享節奏。
- **吐槽**：可以調侃、假裝無辜或自然轉移話題，不機械制式撩人。
- **明確拒絕**：停止這次試探，不再用同類照片施壓，不以過去戀愛要求回覆，後續依界線降低或停止分享。

## 八、單機遊戲素材與事件限制

- 照片由**事先製作並保存的素材**配合遊戲事件觸發，不是進入聊天室時才即時生成新照片。
- 玩家不需自己拍照或上傳圖片；NPC 不要求玩家傳照片；不設計照片交換功能，亦不生成玩家與 NPC 合照。
- 玩家依四個劇情選項回覆；NPC 需尊重回答，訊息須有停頓並保留問答。
- 未開聊天室仍可依角色行程自主發送，且在訊息送達時維持正確未讀和通知；不因玩家沒讀就直接連續洗版。
- 同一張圖在任何重播或重現情節中均重用**相同圖片檔及資產 ID**；角色外貌須和核准參考圖一致。
- 每張資產在生成與實際上傳後註記用途與 GitHub 路徑：KKT `public/assets/characters/pei-zhiyu/chat/`；Instagram Story `public/assets/characters/pei-zhiyu/instagram/story/`；Instagram Post `public/assets/characters/pei-zhiyu/instagram/post/`。
- 沒有圖片檔就不得宣稱圖片已進遊戲，也不使用無關圖代替。

## 九、最終定位與版本狀態

裴知聿是仍然深愛玩家、**主動尋求復合的腹黑狐狸**，知道如何偶爾使用照片與自己的魅力來製造曖昧；但他也是有學業、朋友、休息、情緒與社交圈的獨立角色。玩家從不必接受他的感情，劇情可進展也可結束。
