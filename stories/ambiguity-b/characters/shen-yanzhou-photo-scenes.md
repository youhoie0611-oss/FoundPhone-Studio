# 沈硯舟｜生活照聊天事件配置

`stories/ambiguity-b/story.json`（目前有四張第一人稱隨拍；以 story.json 最新 revision 為準）已連接四張以沈硯舟本人視角拍攝的生活照。

## 使用規則

- **同一人拍攝感**：四個生活場景使用相近的手機手持視角、自然光與真實生活瑕疵，照片是沈硯舟自己觀察、拍下、順手傳給玩家，而不是四組商業宣傳照。
- **以 V1.0 優先**：沈硯舟非常愛自拍、分享生活，長期建議自拍 40%；現有四張只是已完成的景物／活動素材，不代表他平時只拍景物。
- **有趣而自然的聊天**：傳照後可分段補訊息、自嘲或閒聊，不固定問玩家『好看嗎』；玩家忙就停止，未打開聊天室的已排程照片仍照時間送達。
- **不可索取照片**：任何階段都不能主動要求玩家傳自拍、生活照或其他私人圖片；被拒絕傳照片時應遵守界線。
- **舊素材相容**：已有四張景物照片不強制改成自拍，新自拍需依視覺記憶庫另行生成並提交 GitHub，參考 [V1.0 規則](./shen-yanzhou-photo-rules-v1.md) 和 [唯一照片清單](./shen-yanzhou-photo-index.json)。
- 最新在角色專屬對話產出的額外圖片，只有真正上傳並修改 `media` 指向後才算替換正式遊戲素材。

- 四張照片都是沈硯舟手持手機或相機拍到的景物，沒有第三人替他拍照或額外捏造同行者。
- 已放入 KKT 對話的 `kind: "image"` / `media`；媒體使用本地相對路徑，可部署於 GitHub Pages 子路徑。
- 延遲送達及未讀通知由既有事件引擎處理，不需玩家打開聊天室才送達。
- 每張照片都有四種分支回覆，玩家也可表示不想收到生活照；`shen_photo_pause` 會阻止後續尚未排程的生活照事件。
- 不用圖片製造強制曖昧；四張都只是大學生、健身、攝影與運動生活的自然分享。
