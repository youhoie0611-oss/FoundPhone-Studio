# 沈硯舟｜生活照聊天事件配置

此文件對照 `stories/ambiguity-b/story.json` 的正式劇情節點。圖片已存放於 `public/assets/characters/shen-yanzhou/`。圖片是沈硯舟自己的生活紀錄，不能被誤當成玩家的照片或活動肖像授權。

## 共通規則

- 事件依照已有互動與時間間隔觸發，首次認識時不會連續傳自拍。
- 主動訊息會在延遲到期時送達，並不依賴玩家當下是否開啟聊天室；不必回覆才能保留已送達的生活照。
- 每張照片提供四種態度不同的回覆，角色先回答玩家的問題，再繼續自己的生活。
- 若玩家表明不想再收到自拍，設定 `shen_photo_pause=true`，後續尚未開始的生活照事件不再觸發。
- 不擅自提升或顯示戀愛數值，也不把普通照片當作告白或關係確認。
- 實際照片在 `chat.messages` 的 `media` 欄位，使用相對 URL，部署於 GitHub Pages 子路徑仍可解析。

## 驗收重點

1. 確認四張圖片在聊天訊息中可見，不只是 Markdown 註記。
2. 玩家未開啟 KKT 時，已排程的訊息仍按期送達並更新通知。
3. 四個選項有各自的發出訊息與NPC答覆，拒絕後不會無視界線繼續發照。
4. 已存在的 30 輪對話、跨日主動聯絡與重要肖像同意分歧保持原樣。
5. 驗證指令：`npm run story:validate`、`npm run story:test`、`npm run build`，並檢查 GitHub Actions 與實際手機預覽。
