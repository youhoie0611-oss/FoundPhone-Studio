# 全角色衝突與玩家選項強制規範 V4.1

## 反雌競（硬性限制）
女性角色不因男性角色彼此爭風吃醋、不以貶低其他女性換取男性認可、不安排女性間爭奪男性的勝負敘事。女性角色可有獨立職涯、友情、衝突、利益及價值觀分歧；不能因反雌競規則剝奪其主體性。玩家亦不必透過打敗其他女性取得戀愛進展。

## 男性競爭
核心衝突可由沈硯舟、裴知聿、祁野各自的嫉妒、競爭、佔有慾、舊情、心理矛盾推動，但須尊重玩家自主權，禁止以跟蹤、威脅、限制社交或物化玩家作為理想戀愛行為。三人的競爭應有差異：沈硯舟克制與自我懷疑、裴知聿對舊關係的執念及界線修復、祁野的衝動好勝與承擔後果。不可所有人輪流說相同的挑釁台詞。

## 選項 4：玩家自定義（全對話必須）
所有玩家可回覆的對話節點：前三項為符合上下文的固定選項，第四項固定顯示「【玩家自定義】」。第四項必須是真實可輸入文字的互動，而非只顯示同名固定台詞或自動選擇其他選項。允許送出非空自訂文字；應保留原文、寫入聊天紀錄與存檔、交給回覆分支解析（至少能辨識接受／拒絕／提問／轉移話題／設界線／未知），不得默默改寫玩家輸入或強行判定為示愛。角色回覆須符合性格與情境；未知意圖應自然澄清而非假裝理解。禁止空字串、重複送出與跨聊天室串線。

## 實作要求
目前既有故事選項數量不一，僅靠 JSON 新增一個名為「【玩家自定義】」的 action 無法實現自由輸入。必須同步修改 Phone / messaging skin / runtime / schema / 存檔，並增加測試；未完成前不得聲稱功能可用。

## 品質驗收
- 三人及女性配角均無雌競式橋段。
- 男性競爭是角色驅動且尊重玩家決定，沒有強制三角對峙。
- 每一組對話回覆介面顯示三個固定選項及第四個【玩家自定義】。
- 自訂文字能送出、持久化、被角色辨識並合理回覆；存讀檔後不丟失。
- 13 類已禁止的戀愛套路繼續全域生效。

## 男主興趣使用頻率與關係推進去公式化（全域強制）
- 興趣是角色的獨立生活內容，不是戀愛進度按鈕。禁止連續多個關係推進節點都使用同一興趣邀約／展示／教學。
- 沈硯舟不得反覆依賴活動、攝影、課業；裴知聿不得反覆依賴心理學、咖啡、閱讀；祁野不得反覆依賴運動、派對、家世社交。角色興趣可以自行進行，不必通知玩家。
- 禁止固定「展示興趣→邀請→獨處→好感增加」循環。應以具體的衝突、誤判、界線、失約、修復、日常責任、生活變動、價值觀差異推進，亦允許沒有感情進展的日常片段。
- 劇情審查需統計每位男主最近十個關係推進節點的主題與觸發方式；同一興趣作為主要推進手段不得連續重複，過度集中應改寫。這是編劇品質規則，不代表目前引擎已自動檢查。
