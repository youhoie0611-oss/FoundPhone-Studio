# 《磚3》劇情連續性與事件推進｜實作 V11 第一階段

**目標**：以真實遊戲日期、玩家選擇與角色自身日程取代純粹單次聊天。只在 work.title 為「磚3」時啟用新事件引擎；不改動其他遊戲的劇本。保留原 FoundPhone 手機介面，不加入 KKT 自由輸入框。

## 已接入的程式

- `src/brick3/continuityData.ts` 定義 20 段可追蹤事件（五位男主及朋友圈角色），其中每人有多段獨立生活事件；不同角色的主要事件共用同一日曆。
- `src/brick3/continuity.ts` 處理完整的事件紀錄：ID、前置依賴、狀態、玩家是否出席、選項、NPC 反應、約定日期、觸發時間、後續、照片資訊可見性與選擇紀錄。事件狀態支援 not_started/scheduled/active/completed/declined/missed/cancelled/postponed/expired。背景活動不要求玩家開啟 KKT。
- KKT 選項在事件進行時固定 **四項**、均有不同實際行動；不新增訊息自訂輸入欄。邀約階段：接受／拒絕／改期／改成遠端關心；約定階段：取消／改日期／改時間／提前討論事件；抵達階段：明確出席／告知遲到／改期／取消；進入現場後：探查／協助／保持界線／退出。每個選擇保存不同狀態、改變 NPC 後續回覆、線索、關係信任或下一次邀約前情。
- 接受邀約本身**不等於已到場**；有交叉約定時阻擋同一時間雙重接受；沒出席將記為 missed，並改變信任與後續；拒絕仍允許 NPC 活動自行完成。
- 只使用 GitHub 已有的四張圖像：祁野球場、祁野設計桌、顧時安現場、裴知聿研究書桌。圖片被用作場景資訊來源，當事玩家確認到場才出現在該劇情；依據追問選項才寫入相簿與線索。**沒有新生成的人物照片，其他角色缺圖不會偽裝已完成。**
- 陸沉川沿用《陸沉川正式設定 V10》：家族集團副總裁，私人聯絡須已建立才會推進新的私邀劇情。
